# Verified Facebook sales feed

`facebook_sales_verified.csv` is generated by Facebook Sales Scraper v1.5 for Yard Sale Finder v8.

The file begins with headers only; this is not a sample auction list. Your PC updates it after a successful completed scrape with eligible records and a local GitHub sign-in.

Only complete confirmed matches with structured Event dates or explicit dates with a year are published. Dates must match the searched Friday/Saturday. Unknown, yearless, image-only, partial, failed and review records stay local. Descriptions stop before seller details. One row represents one listing/date; the map combines Friday/Saturday rows for a listing into one marker.

Feed URL:

https://raw.githubusercontent.com/Goose67986/Map/main/data/facebook_sales_verified.csv

Columns include `schema_version`, listing ID/title/description, ISO date, source URL, address/coordinates, optional times, verification flag/basis/evidence, searched Friday/Saturday, collection timestamp, price and image URLs. Current schema version is `1`. See the CSV header for the full column list.

The map checks the searched weekend, evidence/verification flag, source URL and collection age (72 hours). Rejected records are not mapped. Browser sessions, credentials and raw review captures are never uploaded. Empty/incomplete scrape runs leave the previous feed in place; old weekends and stale records are ignored by the map.

This CSV does not automatically rebuild `map.html`. Run the updated map-making program to read the latest feed and create the map.
