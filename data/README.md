# Verified Facebook sales feed

`facebook_sales_verified.csv` is generated by Facebook Sales Scraper v1.7 for Yard Sale Finder v8. Your PC updates it after a successful completed scrape with eligible records and a local GitHub sign-in.

Only complete confirmed matches with structured Event dates or explicit calendar month/day dates are published. A written year is optional. Dates such as `10/31`, `October 31`, and `Oct. 30–31` can qualify when they match the searched Friday/Saturday. Missing years are assigned near that searched weekend; years actually written in a listing are respected. Bare weekdays, “tomorrow,” image-only dates, search-card-only evidence, partial/failed reads, and review records stay local. Posting dates and seller-detail text are excluded from date evidence.

The user sets Facebook's “listed in the last 7 days” filter manually; the scraper does not independently certify that filter. Descriptions stop before seller details. One CSV row represents one listing/date; the map combines Friday/Saturday rows for a listing into one marker.

Feed URL:

https://raw.githubusercontent.com/Goose67986/Map/main/data/facebook_sales_verified.csv

Columns include `schema_version`, listing ID/title/description, ISO date, source URL, address/coordinates, optional times, verification flag/basis/evidence, searched Friday/Saturday, collection timestamp, price and image URLs. Current schema version is `1`. Supported verification bases are `structured_event_date`, `explicit_date_with_year`, and `explicit_month_day`. Month/day evidence records the date text, assumed-year flag, searched reference date, and normalized matching dates.

Install the updated v8 map-making script alongside scraper v1.7: earlier v8 copies do not accept `explicit_month_day`. The map checks the exact searched weekend, calendar evidence/verification flag, source URL, and collection age (72 hours). Browser sessions, credentials and raw review captures are never uploaded. Empty/incomplete runs leave the previous feed in place; old weekends and stale records are ignored by the map.

To recheck a saved completed run without opening Facebook, run `upload_saved_results.bat` or `facebook_sales_scraper.py --upload-latest` on the PC. This republishes only eligible rows for the configured searched weekend.

This CSV does not automatically rebuild `map.html`. Run the updated map-making program to read the latest feed and create the map.
